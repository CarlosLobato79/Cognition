# Cognition

Entrenamiento cognitivo inmersivo para memoria, atención y control de secuencias.

## Desarrollo

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
```

## Primera pantalla

La versión inicial contiene la pantalla de carga de Cognition: fondo oscuro, logo cerebral vectorial, animación de entrada con Anime.js y estado oscuro posterior al arranque.
